Why regctl?

Multi-Registrar Price Compare

Instantly compare prices across Spaceship, Porkbun, Cloudflare, and Value Domain with one command.

Register at Cheapest

Auto-selects the cheapest registrar with API support. Register with regctl domains register.

Unified DNS Management

Manage DNS records across all registrars with regctl dns list/add/delete.

AI-Friendly Output

Use --format json for structured output. Works with Claude, GPT, and other AI tools.
