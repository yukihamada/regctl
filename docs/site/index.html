regctl

Domain management CLI for Value Domain. AI-friendly output.

Install

# Mac / Linux / WSL
curl -fsSL https://regctl.com/install.sh | sh
# Or with Go
go install github.com/yukihamada/regctl/cmd/regctl@latest

Quick Start

regctl init                              # Setup wizard
regctl domains list                       # List domains
regctl domains check example.com          # Check availability
regctl dns list example.com               # DNS records
regctl dns add example.com -t A -n @ -c 1.2.3.4
regctl domains list --format json         # AI-friendly JSON
regctl server                              # Start API server

Interactive Mode

Run regctl with no args for a guided menu. Setup wizard included.

AI-Friendly

--format json returns structured data with next_steps hints.

HTTP API

Built-in REST server. Deploy to Fly.io with one command.

Zero Config

One binary, no dependencies. Works on Mac, Linux, Windows.
